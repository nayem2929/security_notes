Domain Name System: Basically an IP address to domain name resolution. Phonebook of the internet.

**Top Level Domain** (TLD): The rightmost part of the web address. There are two types of TLDs. gTLD(generic TLD) and ccTLD(country code TLD, e.g. .ca, .co.uk etc.). gTLDs are meant to tell user about the purpose of a website. For example, .com is for commercial use, .gov is for govt use, etc. TLDs are limited to 63 characters between A-z and 0-9.
Second Level Domain: the part before the TLD. Limited to the same restrictions as the TLDs.
Subdomain: The part before the Second Level Domain. Same limits as TLDs but can be dodged using periods, but max 253 chars.

***Record Types***:
A record: To resolve IPv4
AAAA record: To resolve IPv6
CNAME record: To resolve to another domain
MX record: Resolves to email servers and tells which order to try the servers
TXT record: Strings of texts that list the servers that have the authority to send emails on behalf of the domain.
