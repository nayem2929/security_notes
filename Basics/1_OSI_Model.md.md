**Layer 1 - Physical**: The physical signals, cables, and connectors.

**Layer 2 - Data Link**: Switches sending packets to MAC addresses using DLC protocols.  

**Layer 3 - Network**: Routers using OSPF to route traffic to different IP addresses

**Layer 4 - Transport**: The layer that decides what Transport Layer protocol (TCP or UDP) to use to send the data

**Layer 5 - Session**: Responsible for dialogue control, synchronization, authentication and authorization. 

**Layer 6 - Presentation**: Works with the application layer to transfer information like fonts, sizes etc. and invokes encryption protocols like SSL or TLS.

**Layer 7 - Application**: This is the UI layer that also describes the purpose of connection with protocols like HTTP, FTP, DNS etc.
