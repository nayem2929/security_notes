**Port forwarding:** This is just a way to configure a router to open up a specific port to the internet.

**Firewalls:** The servers bouncer. It does packet inspection and finds out things like origin, destination, protocol, port number request for the packets before allowing them entry. Two ways to categorize firewalls would be:

-        Stateful: Dynamic decision making, smarter but costs more resources.

-        Stateless: Static, dumb firewalls that are light on the machine, effective against simple attacks like DDoS.

**VPNs:** Virtual Private Network is a tunneling technology that allows users to connect to an internal system using a secure path. This path is encrypted, so it protects users by offering privacy and anonymity. Some existing VPN technologies are listed below:

-        PPTP (Point-to-Point Tunneling Protocol) allows authentication and encryption using PPP.

-        IPsec uses existing IP framework. More difficult to set up than PPTP but better encryption.
